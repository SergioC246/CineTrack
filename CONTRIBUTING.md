# Contributing to CineTrack

Thanks for your interest in contributing!

## Setup

1. Clone the repo: `git clone https://github.com/SergioC246/CineTrack`
2. Install dependencies: `npm install`
3. Create a `.env` file based on `.env.example`
4. Run the dev server: `npm run dev`

## Backend

1. Navigate to backend folder: `cd backend`
2. Install dependencies: `npm install`
3. Create a `.env` file based on `.env.example`
4. Run the backend: `npm run dev`

## Guidelines

- Follow the existing code style (TypeScript, ESLint)
- Write clear commit messages
- Open an issue before submitting big changes

## Reporting bugs

Open an issue with steps to reproduce and expected vs actual behavior.
